# Sprint 11 — Assurance and production-readiness assets

- Adds a CodeQL workflow for Java, TypeScript/JavaScript and Python static security analysis.
- Adds a k6 load-test script for health and authenticated community-resource reads.
- Adds an edge smoke-test script for API health and optional Prometheus reachability.
- Adds operations and production-readiness checklists covering security, offline fault injection, backup/restore, Rwanda governance, community pilot and release gates.

This sprint provides repeatable assurance assets and explicit acceptance criteria. It does not perform a penetration test, execute a real load test, complete a disaster-recovery drill, or conduct a Rwanda field pilot. Those require a controlled staging environment, real devices, qualified reviewers and participating communities.
